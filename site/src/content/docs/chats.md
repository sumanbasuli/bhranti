Use one chat for a connected piece of work, such as updating your About page. Start a new chat when you move to a different project. Your conversations are private to your WordPress account through Bhranti’s interface.

## Open and close Bhranti

Select **Bhranti** in the WordPress admin bar to open the sidebar. The post/page editor also provides a Bhranti opener when the admin-bar control is unavailable. Select **Close Bhranti** in the sidebar header to close it.

The sidebar stays open as you navigate between WordPress admin pages. When you switch to viewing the site, open Bhranti again if needed. Closing the sidebar is not the same as stopping a task: eligible work can continue through WordPress scheduling. Use **Stop** if you want the task to stop between steps.

While a site change is being saved, Close may briefly be unavailable with the explanation **Available after the current change finishes**. The chat and Stop remain accessible while Bhranti protects the ongoing action.

## Start a new chat

1. Open Bhranti.
2. Select **New chat**, the plus icon in the **header**.
3. Type your request in the message box.
4. Check the context chips and attachments, then select **Send message**.

The plus icon beside the message box is a different control: **Attach current page context**. It does not start a chat.

New chat is unavailable while the current task is active, an image is being prepared, or the sidebar is loading. Wait for the task to finish, or use Stop and allow its current step to end.

## Continue an earlier conversation

1. Select **Chats** in the sidebar header.
2. Use **Search chats…** to filter the displayed list by conversation title.
3. Select a conversation. Its messages, action history and available work plan open in the sidebar.
4. Send a follow-up in the same chat when it relates to that work.

[![The Chats menu filtered by the word theme, with an existing conversation selected and Delete this chat below it.](/images/docs/chat-history.jpg)](/images/docs/chat-history.jpg)

*Search filters conversation titles. Delete this chat appears below the list when an existing saved conversation is open. Select the screenshot to view it at full size.*

The chat list shows the latest 50 conversations. Search filters the titles in that list; it is not a full-text search across every message. The current conversation is marked in the list. Chat switching is disabled while a task is active.

A conversation holds up to 200 messages, including Bhranti’s replies. When the limit is reached, start a new chat for the remaining work. The chat shows the latest 100 actions; use [Logs](/docs/logs-and-recovery/) to search older activity, follow a task or download its records. You can also ask Bhranti to explain the logs for this conversation without making changes.

Conversation titles are derived from the initial request. There is no separate rename control in the current sidebar.

## Write and keep a draft

Press **Enter** to send, or **Shift+Enter** to add a new line. The message box accepts up to 12,000 characters per submitted message.

You can draft your next message while Bhranti is working. Send stays disabled until the active task reaches a state that can accept input. If Bhranti asks you a question, answer in that same chat.

Your unsent text stays with its conversation when you switch chats in the same browser tab. Drafts are not shared across devices. You may need to reattach an unsent image after refreshing or closing the tab.

## Delete a conversation

1. Open the conversation you want to remove.
2. Wait for its task to finish, or Stop it and wait for the current step to end.
3. Select **Chats**.
4. Select **Delete this chat** below the conversation list. Scroll the Chats menu if the list is long.
5. Read the browser’s confirmation and confirm only if you want to delete that conversation permanently. Cancel keeps it.

Deleting a chat removes its private conversation data, work plan and rollback records. It **does not undo changes to your site** or remove their audit entries from Logs. If you need to restore a supported edit, use [Roll back](/docs/permissions-and-undo/) before deleting its conversation.

## Read long conversations comfortably

Completed actions may be grouped under **completed actions**. Expand the group, then expand an individual action to see its summary, time, affected item and any Roll back control. Failures and approvals remain visible.

Use **Jump to latest** when you have scrolled up and want to return to the newest message. Use **Copy response** beside an assistant reply to copy the reply.

Press **Escape** to close an open Chats menu first; with the menu closed, Escape closes the sidebar when it is safe to do so.

On a desktop-sized screen, drag the sidebar’s left edge to resize it. You can also focus **Resize Bhranti sidebar** and use the left or right arrow key.

## Choose an agent

If your administrator has added more than one agent, **Chats** also contains an **Agent** selector. Choose an agent before your next request. The selector is unavailable during an active task.

[Agents and skills](/docs/agents-and-skills/) explains how to create these instructions and when changes take effect.
